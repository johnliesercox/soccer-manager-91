# Soccer Manager '91

A phone-first football management game in the spirit of the 1991 Amiga originals. The playable game is one HTML file (`index.html`) plus a manifest, a service worker and two icons; everything else in this repository is the source it is built from.

Live at https://johnliesercox.github.io/soccer-manager-91/

## What is in this repository

| Path | What it is |
|---|---|
| `index.html` | The built game that GitHub Pages serves. Do not edit by hand; it is generated by `build.py`. |
| `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png` | The "add to home screen" app files. `sw.js` holds the `VERSION` string that makes installed phones pick up a new release. |
| `worker/` | The optional Cloudflare Worker for the shared ladder (see `worker/README.md`). |
| `engine.js` | The game engine: clubs, players, the season, the match simulation. Also loads in Node for the tests. |
| `ui.html` | The screens and styles, with two slots (`/*ENGINE*/` and `/*MATCHDAY*/`) that the build fills in. |
| `src/matchday/` | The animated match viewer: capture, timeline, behaviour, trajectories, interactions, scene, playback, sprites, audio, the viewer UI and the three renderers. |
| `build.py` | Inlines `engine.js` and the matchday modules into `ui.html` and writes `index.html` (and `soccer-manager-91.html`, a copy without the app links that opens straight from disk). |
| `test-*.js`, `harness.js`, `sim.js` | The automated tests and the headless harness they use. |
| `legacy/` | Old engine snapshots that the migration tests load. |
| `ARCHITECTURE_MATCHDAY.md` | How the match viewer fits together and the contract for the next renderer (isometric or 3D). |

## Rebuilding after a change

```
python3 build.py
```

That rewrites `index.html`. To run the tests (Node 18 or later; the first time run `npm install` to fetch the headless canvas and DOM):

```
node test-matchday.js
node test-playback.js
node test-matchday-ui.js
node test-phase25.js
node test-equivalence.js
node test-regression.js
```

Each prints a final "PASSED" or "errors: none" line.

## Putting it online with GitHub Pages

1. Create a repository called `soccer-manager-91`.
2. Upload the contents of this folder (**Add file > Upload files**, drag everything in) and commit.
3. **Settings > Pages**: Source "Deploy from a branch", branch `main`, folder `/ (root)`. Save. The URL appears after a minute.

Open it on your phone. In Safari tap Share > **Add to Home Screen**; in Chrome on Android use the menu > **Add to Home screen**. It then opens full screen, works offline, and saves live in the browser on that phone.

## Releasing an update

Upload the new files over the old ones (same drag and drop) and commit. Players get the new version the next time they open the game online; their saves carry over because the game migrates old save formats. The `VERSION` string in `sw.js` is bumped with every release so offline installs refresh too.

## Feedback link

In `ui.html`, near the top of the script, set `const FEEDBACK_URL = '';` to a Google Form link and a "Send feedback" button appears on the title screen (then rebuild).

## Version history

* **1.4 (Phase 2.5): believable football.** A deterministic role planner (`src/matchday/behaviour.js`), bounded trajectories in metres per second (`trajectories.js`) and explicit ball-action beats (`interactions.js`) feed the shared scene that every renderer draws. Results are untouched. Desktop two-column match screen. `ARCHITECTURE_MATCHDAY.md` carries the Phase 3 handover contract.
* **1.3: pixel stadium.** Pixel-art players generated in code and recoloured per kit, a referee, stands and a crowd, with a camera that follows the ball.
* **1.2: matchday.** Watch your match on an animated top-down pitch, or take the instant result. The viewer never changes a result.
* **1.1.** Contracts and morale, bookings and suspensions, the youth academy, club records and the hall of fame, challenge starts, and a shared ladder (needs the worker). Saves are compressed so that eight named saves fit.

## Notes

* Saves are stored in the browser on that phone (localStorage). Clearing site data clears them. The in-game Saves screen keeps up to eight named copies.
* Club and competition names are the real 1991 ones. If the game ever grows beyond a hobby release, swap them for fictional ones; the rename screen already exists for this.
